# Droovo — fiche stores

## Nom

Droovo

## Sous-titre / description courte

Livraison collaborative sur des trajets déjà prévus.

## Description

Droovo met en relation les personnes qui souhaitent envoyer un colis avec des transporteurs effectuant déjà un trajet compatible.

- publiez un colis et obtenez un prix avant de vous engager ;
- déclarez un trajet et consultez les colis compatibles ;
- choisissez votre interlocuteur ;
- suivez les étapes de remise et de livraison ;
- utilisez un paiement sécurisé avec vérification d’identité.

Les paiements et coordonnées bancaires sont traités par Stripe. Les distances sont calculées à partir des adresses sélectionnées lorsque le service cartographique est configuré.
